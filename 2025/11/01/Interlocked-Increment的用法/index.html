C# 中的 Interlocked.Increment 详解
在多线程编程中，线程安全是一个至关重要的话题。当多个线程同时访问和修改共享变量时，如果没有适当的同步机制，就会导致数据竞争和不一致的结果。C# 提供了 Interlocked 类来解决这类问题，其中 Interlocked.Increment 是一个非常重要的方法。

1. Interlocked.Increment 概述

Interlocked.Increment 是一个原子操作，用于以线程安全的方式递增指定变量的值。所谓”原子操作”是指这个操作在执行过程中不会被其他线程中断，要么完全执行，要么完全不执行。

问题根源

counter++ 看起来是一个简单的操作，但实际上它包含三个步骤：

  1. 从内存读取 counter 的值到寄存器
  2. 在寄存器中递增该值
  3. 将新值写回内存

在多线程环境中，可能会出现这样的时序问题：

  • 线程 A 读取 counter 值为 100
  • 线程 B 读取 counter 值也为 100
  • 线程 A 递增到 101 并写回
  • 线程 B 递增到 101 并写回
  • 结果：两次递增只增加了 1！

4. Interlocked.Increment 的工作原理

Interlocked.Increment 在底层使用处理器的原子指令（如 x86 架构的 LOCK INC 指令）来确保操作的原子性。这些指令会：

  1. 锁定内存总线：防止其他处理器访问同一内存位置
  2. 执行递增操作：在单个不可中断的步骤中完成
  3. 释放锁：允许其他处理器访问内存

10. 总结

Interlocked.Increment 是 C# 多线程编程中的重要工具，它提供了：

  • 线程安全：确保递增操作的原子性
  • 高性能：比传统的 lock 语句更高效
  • 简单易用：API 设计简洁明了

在需要高性能计数器、唯一 ID 生成、资源统计等场景下，Interlocked.Increment 是最佳选择之一。然而，对于复杂的同步需求，可能需要结合其他同步机制如 lock、Monitor、Semaphore 等来满足需求。
